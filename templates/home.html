Amazon EC2

COMPUTE

Virtual servers, instance types, AMIs and instance lifecycle management.

Practice →
What is EC2?
EC2 provides virtual servers called instances. An AMI is the server image, an instance type defines compute capacity, and a security group controls network traffic.
Practice: Launch, stop and start simulated instances in the EC2 Lab.

Amazon S3

STORAGE

Object storage, buckets, object metadata, versioning and access concepts.

Practice →
What is S3?
S3 stores objects inside buckets. Object storage is useful for images, backups, logs and static files. Bucket names must be globally unique in real AWS.
Practice: Create simulated buckets and add object metadata. This lab does not upload actual files to AWS.

AWS Lambda

SERVERLESS COMPUTE

Functions, event-driven computing, execution roles, triggers and logs.

Open Lab
What is Lambda?
Lambda runs code in response to events without requiring you to manage servers. Events can come from services such as S3, EventBridge or API Gateway.
Example: An image uploaded to a bucket triggers a function. Real AWS execution and permissions are not configured in this learning preview.

Amazon VPC

NETWORKING

Virtual networks, subnets, routes, gateways and network security.

What is VPC?
A VPC is an isolated virtual network. Subnets divide its IP address range. Route tables decide where traffic goes. Internet and NAT gateways serve different connectivity needs.
