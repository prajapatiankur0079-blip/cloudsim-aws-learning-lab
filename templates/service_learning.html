3. Security and reliability checklist

  • Apply least privilege: grant only the access required for the task.
  • Protect credentials and never paste access keys into source code or public repositories.
  • Check network access and resource policies rather than opening everything to the internet.
  • Enable suitable logs, metrics, alerts and audit records.
  • Plan for failures, backups or recovery where the service supports or requires them.
  • Estimate costs and clean up real cloud resources when they are no longer needed.

4. Troubleshooting guide

Common starting point: {{ lesson.issue }}

  1. Reproduce the issue and note the exact error and time.
  2. Check service status, configuration, identity permissions and network connectivity.
  3. Read the relevant logs or events and change one thing at a time.
  4. Repeat the test and document the cause and fix.
