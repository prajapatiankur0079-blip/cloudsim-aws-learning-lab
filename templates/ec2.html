UNDERSTAND

What is EC2?

Amazon EC2 lets you run virtual servers in the cloud. You choose the operating system and computing capacity for your application.

Example: Hosting a website on a cloud server instead of keeping your laptop switched on.

KEY CONCEPT

Instance states

Running: The simulated server is on.

Stopped: The server is off but retained in this lab.

Terminated: The simulated instance is removed.
