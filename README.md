# CloudSim AWS Learning Lab

An interactive AWS infrastructure learning simulator built with Python, Flask, and SQLite.

## Features

- VPC and subnet CIDR practice
- Subnet overlap validation
- Routing and NAT concepts
- EC2 simulation
- S3 storage concepts
- Security Group rules and traffic testing
- Local SQLite database

## Tech Stack

- Python
- Flask
- SQLite
- HTML and CSS
- Git and GitHub

## Installation

Clone the repository:

    git clone https://github.com/prajapatiankur0079-blip/cloudsim-aws-learning-lab.git
    cd cloudsim-aws-learning-lab

Create and activate a virtual environment:

    python3 -m venv venv
    source venv/bin/activate

Install Flask:

    pip install Flask

Run the application:

    python app.py

Open http://127.0.0.1:5000 in your browser if Flask reports that address.

## Important Notes

This is a local learning simulator, not the actual AWS cloud. Resources are simulated for educational purposes.

Never commit passwords, personal access tokens, private keys, or local database files.
